# PennyWise Mobile App

This is the flagship financial literacy app for kids aged 5-17, built with React Native and Expo.

## Tech Stack
- **Framework:** React Native + Expo (SDK 56)
- **State Management:** Zustand
- **Navigation:** React Navigation
- **Styling:** NativeWind (Tailwind CSS)
- **Data Fetching:** TanStack Query
- **Persistence:** Expo SQLite
- **Animations/Games:** Reanimated, React Native Skia

## Getting Started
1. Install dependencies: `npm install`
2. Run the app: `npx expo start`

## Project Structure
- `src/assets/`: Static assets (images, fonts).
- `src/components/`: Reusable UI components.
- `src/features/`: Feature-specific logic and screens.
- `src/navigation/`: Navigation configurations.
- `src/store/`: Global state management.
- `src/utils/`: Helper functions.
